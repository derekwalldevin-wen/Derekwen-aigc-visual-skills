# Examples

Each Skill has a real generated raster example, with an independently prepared source input and a separate image-edit output.

- Image Skills: `before.png` + `after.png`.
- Video Skill: `before.png` + `preview-frame.png` (static **Video Preview**).
- Each folder includes source review, exact prompts and input-to-output mapping in `README.md` and `generation.json`.
- All publication candidates used here are **A — Public Safe** under the owner's task policy. The original 德小文 IP reference was reused; the remaining sources are newly generated fictional people, scenes and a product.
- Historical identifiable-person candidates with uncertain source rights were classified **B — Rights Unclear** and excluded in full, including derived outputs. No **C — Do Not Publish** material was admitted.
- The old simplified character board was reviewed but replaced with a full board generated from a cleaned original-IP reference. No brand-bearing workshop background was published.
- The memory portrait is a fictional demonstration, not a real biography.
- The video frame is generated directly from the product source; no completed film is represented.

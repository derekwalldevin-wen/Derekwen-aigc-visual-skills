# 穿搭上盘｜Outfit on a Plate

**2026-11-09 · 已生成六张真实案例 · GitHub 栅格原图待上传**

把一位人物的全身穿搭拆成一个餐盘内的白边模切贴纸配方，保留人物相纸作为服饰来源证据。输出3:4单张时尚静物视觉；支持“中文主标题+英文副题”和真正无字。

## 使用示例

```text
使用 outfit-on-a-plate。参考我上传的一张清楚的全身穿搭照，
仅把看到的外套、内搭、下装、鞋和包分别变成白边纸质贴纸，
放在一个有质感的餐盘上；一张全身相纸在旁边。
贴纸一一对应，无增减，单张3:4，中文主标题+英文副题。
```

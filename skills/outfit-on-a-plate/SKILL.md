# 穿搭上盘｜Outfit on a Plate

## 创作目标与适用场景

把一位人物**实际可见**的完整穿搭变成放在一个有真实材质的餐盘里的白边模切纸贴，并在同一桌面场景展示原始全身穿搭相纸。重点是像时尚杂志静物摄影，而不是把衣服拼成食物，也不是制成多页说明板。

适用：穿搭清单视觉化、杂志封面、服装详情说明、面向社媒的“逐件对应”互动、不同风格对照。默认单张 **3:4竖版**；图像工具本次实际输出为 **1086×1448**，不可把目标高分辨率说成已实测输出。

## 输入与变量

| 变量 | 用法 |
|---|---|
| 【源图】 | 一位成年人的本人/获授权全身穿搭照；人物、鞋、包、配饰尽量清楚可见。没有源图可先生成虚构成年模特参考。|
| 【主题】 | 穿搭场合与视觉调性，如先锋时尚、周末日常、职场、晚宴、城市运动、海边度假。 |
| 【图片职责】 | 封面、可复制用法、无字案例、结构对应、细节控制、单品互动。 |
| 【参考图职责】 | 指明照片是人物身份、服饰清单的唯一来源；背景不作为单品。 |
| 【服饰清单】 | 逐项列出颜色、版型、面料、纹理、可见零件，标明分组数。 |
| 【盘中对应规则】 | 每一实物单品恰有一个对应纸贴组；鞋一双算一组，包单个算一组。 |
| 【人物呈现】【画面组织】【镜头】 | 控制相纸位置、人物全身无遮挡、餐盘占比、镜头与留白。 |
| 【主色与材质】【餐具与环境】【互动任务】 | 控制盘釉/金属、织物/纸厚、配色、互动关系，避免无关装饰。 |
| 【文字模式】【中文主标题】【英文副题】【中文底句】 | 有字双语/无字；无字需把三个文字字段全部设为空。 |

## 执行步骤

1. **审核源图与权利**：真实人物仅处理本人或已获授权的照片；公开案例优先用本次生成的虚构成人参考，不推断真实身份。
2. **列真实穿搭事实清单**：从头到脚逐件核对颜色、衣物版型、面料、鞋、包、帽；外套/内搭独立计数，鞋以一双为一组。
3. **一一映射到贴纸**：每组服饰在盘中转为独立白边模切纸贴，保留衣物结构，纸边真实微翘，不在盘中重新穿到模特身上；不得遗漏、重复、臆加。
4. **形成单一桌景**：一个有质感的餐盘，旁边仅放一张人物全身相纸；使用高级时尚杂志静物摄影、自然左上侧光、可信接触阴影和留白。
5. **填入模板**：仅替换下面母模板的【】变量，不向固定段落追加互相冲突的指令；按需双语或无字。
6. **实际出图**：让图像工具直接生成完整3:4单张图，包含原生标题（如有），**不得用程序排版或后期替字来冒充已实测流程**。
7. **逐图验收**：数源图服饰、数盘中贴纸、查细节和中英文/无字模式；单项失败只重做当前图。多个不同场合应改变人物、服装和桌景，不要只更换标题。

## 关键控制点

- **照片只是出处依据**：保留人物原样和全身造型；不能额外生成人物、错换衣服、遮住鞋包。
- **盘中数量精确**：每项对应一张贴纸，鞋成双、包独立、帽独立；最终版**不采用故意漏件分支**。
- **物体仍是纸贴，不是食物**：白色模切边、厚度与翘角、衣物色彩和纹理清晰。
- **可见优先**：不自行加领带、内搭、珠宝、Logo/品牌；没有看见的结构不得编造。
- **文字双语主次**：汉字主标题至少为英文副题三倍高；只输出指定字串，不加伪文字；无字模式清空全部文本字段。
- **一张图一个摄影场景**：禁止多宫格、手机样机、规则讲解板、元素重叠遮挡与随机海报拼贴。

## 失败纠偏

| 失败症状 | 纠正动作 |
|---|---|
| 盘中丢了帽子、包或鞋子 | 先重核穿搭清单，再强制写出“盘中恰好N组，每组具体名称”。 |
| 外套与内搭粘在一起 | 指定“外套/衬衫分别是独立纸贴，人体不可出现在盘中”。 |
| 盘中鞋只剩一只，或者包变形 | 明确一双鞋算一组、包为独立单品；重点约束鞋头、包带与肩带。 |
| 人物照片裁脚/被标题盖住 | 缩小相纸或移动餐盘，并保留人物从头到鞋的全身证据。 |
| 额外添加手饰、腰带、Logo | 强化“只依据可见物件，不加未列明物件”；删掉装饰性品牌。 |
| 无字图出现占位符/乱码 | 将三个文字字段置空并写明“移除所有字符、数字、字母和占位”。 |
| 六张都是同一个桌面换标题 | 逐张改变人物、服装版型、餐盘材质、镜头与互动任务。 |
| 纸贴像食物/塑料玩具 | 强调白边模切印刷纸、真实薄纸卷边和纸面阴影。 |

## 质量验收

- [ ] 原相纸只有一位成年人物，完整清晰，无穿搭遮挡。
- [ ] 源图所有可见衣物/鞋/包/帽在盘里逐件一一对应。
- [ ] 未多添、未遗漏、未合并，鞋成双且以一组计。
- [ ] 不改变关键颜色、廓形、材质或品牌归属。
- [ ] 单张3:4，无违规拼版/手机样机/缺件“找错”套路。
- [ ] 双语字串逐字正确；无字图完全无文字。
- [ ] 图像与原参考属于同一搭配、摄影逻辑连贯、纸贴质量可信。
- [ ] 公开案例无来源不明真人、客户隐私、受限素材或第三方商标。

# 照片入青绿 / Photo to Qinglv

将现代日常照片转换为上下双生海报：上半是保留人物与场景的摄影质感，下半是石青石绿层染的传统青绿山水表达；标题以瘦金体笔意融入绢白留白。

[完整 SKILL.md](./SKILL.md) · [最终母提示词](./references/mother-template-v1.txt) · [案例记录](../../examples/photo-to-qinglv/README.md)

## 使用

```
使用 photo-to-qinglv，根据我上传的照片生成3:4上下双生海报。
原片主体与背景关系保持一致，青绿转绘使用石青石绿层染和细墨线；
中文标题【雨站入青绿】，英文【RAIN IN AZURITE】，上半标注【原照片】。
```

已有三张已交付的 AI 写实输入案例；**图片正本尚待上传仓库**，不使用占位或失效图片链接。具体实测边界见案例记录。

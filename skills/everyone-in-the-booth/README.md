# 全员进棚｜Everyone in the Booth

**同一张合照，上半是日常，下半是出道现场。**

将清晰的多人合照变成3:4单张上下双生对比图，严格锁定同一批人的**人数、左右顺序、脸、发型与主要服装**；下半进入复古录音棚，按主唱、和声、歌词、打拍子和笑场等分配不同动作。

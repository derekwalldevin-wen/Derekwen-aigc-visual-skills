# 物件成兽｜Object to Mech Beast

## 创作目标

上传一张日常物件照片或指定一个普通物件，让它**从自身结构长出动物的身体**。不是将动物贴在物体旁边，也不是把物件完整包进动物外壳。物件的上盖、铰链、开关、镜头、把手、通风孔、电线等必须各自承担明确的动物解剖功能，且能够顺着原有工程结构找到合理的变形路径。

默认输出一张3:4竖版、高完成度、单主体的概念视觉图；只有要求教程或社媒海报时再叠加中英文字。可用写实材质的电影级概念摄影，也可用精细工业产品概念插画，但必须让物件辨识度优先。

## 输入

- 【物件／照片】：订书机／胶片相机／吹风机／剪刀／电话／其他家居物件；用户上传照片时必须基于该照片的特征。
- 【动物】：鳄鱼／甲虫／深海鱼／蜻蜓／章鱼／其他，推荐依据物件现有运动关节、通道和轮廓选择。
- 【结构映射】：至少三处“原有部件 → 动物器官”；例如“订书机上盖 → 上颚”。
- 【姿态】：低伏张嘴／攀爬／悬浮游动／展开翅膀／盘踞桌面。
- 【场景】：深灰桌面／苔石／深海暗场／雨后池塘等。
- 【光线】：侧向暖光／金属轮廓光／自然逆光等。
- 【画面模式】：无字单张（默认）／单张中英标题海报／三阶段结构演变教学图。
- 【比例】：默认3:4。
- 【材质锁定】：保留原照片的金属、塑料、橡胶、镜头玻璃、旧化、主色与表面磨损。

缺少图像时可以原创物件造型，但不要声称精确还原未提供的源照片。

## 结构优先：核心工作流

1. **识别原物件**：列出5个最有辨识度的部件、材质与可动机构，锁定至少3个。禁止为追求“像动物”而把原物件彻底替换掉。
2. **选择相容动物**：让动物的运动模式匹配原物件功能——订书机开合像鳄鱼颌，相机镜头像甲虫头部，吹风机风口像鱼嘴，剪刀双刃像蜻蜓翅，电话卷线像章鱼腕足。
3. **建立结构映射表**：每个新生物部位须标出原始来源，关节建立在已有铰链、轴承、接缝或工程可信的位置。新增辅助构件保持少量。
4. **确定独特姿态**：按所选动物设计重心、足部接地、翅膀张力、水下流线或爪部抓握，避免随意拼装的机器人模型。
5. **保留物件身份证**：原始轮廓、颜色、尺寸比例、材质和标志性结构仍能一眼读出；避免无授权品牌商标与不存在的结构。
6. **完成灯光与场景**：与动物姿态匹配的接触阴影、反射、遮挡和镜头透视；保持单个主角与清楚的视觉中心。
7. **质量检查**：用“先看出是什么物件，再看出是什么动物，再追溯部件怎么变化”的阅读次序验收。

## 快速可复制提示词

将【物件】转换为一只【动物】形态的精细机械生物。完整保留原物件的主体轮廓、【主色】、材质、比例与可辨识功能部件；让【部件A】构成【器官A】、【部件B】构成【器官B】、【部件C】构成【器官C】。动物的解剖与姿态清晰合理，关节优先从原物件真实铰链与接缝中生长，不将物件埋入通用机甲外壳。姿态为【姿态】，场景为【场景】，采用【光线】；丰富机械微细节、真实接触阴影与反射。3:4竖版，单一视觉主体，产品概念海报级视觉，默认无文字、无水印。

## 海报模式与标题设计

默认无字原生概念图。明确要求社媒海报时可添加简洁的中文大标题与英文副标，如“物件成兽 / OBJECT TO MECH BEAST”。文字应与画面材质和视线方向融合；订书机鳄鱼、相机甲虫、吹风机深海鱼可各自配独立中英标题。不要用六宫格替代每张单独案例。文字版出现字形异常时优先修正标题排版，不改变已合格的生物结构。

## 三阶段教学模式（仅用户指定）

在**同一张图**中安排：物件原貌 → 核心机构展开 → 机械动物完成体。每个阶段共享颜色、比例与来源结构，通过清楚的运动箭头说明变形因果。三阶段是视觉概念，不代表已生成可执行的机械运动机构或可3D打印结构。

## 失败判定与调整

- 物件消失、只剩普通机械动物：提升原物件轮廓与功能部件占比，锁定颜色、连接件位置和材质。
- 物件上粘了一只动物：删除外贴动物装饰，强制以原装置机构构成动物器官。
- 关节和受力不可信：将运动轴、足部接地和尾部连接回原始铰链、接缝或可解释的机械节点。
- 不像指定动物：加强该动物的头身比、步态、口鼻、翅膀或鳍尾的剪影特征。
- 过度赛博／通用外骨骼：减少额外装甲和霓虹，恢复原物体实材质。
- 手柄／电源线突兀：让它成为尾、足、鳍或触手的结构延续，同时保留物件身份。
- 文字盖住主体：提高留白，改标题位置和字形；不牺牲机械兽主体识别度。

## 验收标准

必须同时成立：原物件可识别；动物种类可识别；至少3个关键器官能追溯到原始部件；关节连接可信；颜色材质一致；主体与场景有物理关系；构图明确；没有未经要求的品牌或水印。若使用用户上传素材，仍须审核公开传播许可。

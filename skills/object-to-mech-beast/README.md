# 物件成兽 / Object to Mech Beast

把订书机、相机、吹风机等日常物件的**真实功能结构**变成机械动物。物件原有部件就是动物的关节、嘴、眼、鳍、翅或触手。

- **输出：**3:4 单主体概念图；可选社媒中英标题／单张三阶段结构图
- **核心：**结构映射优先、原物件身份锁定、动物解剖清晰、真实材质
- **日期：**2026-11-04
- **Case：**[dw-object-to-mech-beast](../../data/cases/dw-object-to-mech-beast.yaml)
- **教程：**[每日一词｜物件成兽](../../daily-words/2026/11/object-to-mech-beast.md)

## 快速调用

```text
使用 object-to-mech-beast：把红色金属订书机变成鳄鱼。
订书机上盖成为上颚、钉仓成为下颚与牙床、原有铰链成为颌关节。
保留订书机红色外壳、金属钉仓和比例；低伏在深灰桌面、微张嘴、暖色侧光。
输出3:4无文字单主体概念图。
```

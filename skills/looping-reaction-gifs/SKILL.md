# 动态聊天表情包｜Looping Reaction GIFs

## 目标与适用场景

根据原创角色参考图，制作可直接用于聊天回复的**单张、正方形、可循环的 GIF 表情包**。把一句短语转换成具体的面部表情与肢体语言；避免僵硬摆动、镜头闪烁和人物走形。已能核实的2026-11-05示例包括“收到！”和“好玩！”的480×480、16帧循环GIF，以及“我就看看”等探索版本。用户明确要求1:1、节奏自然、动画连贯。

GIF应以原生动画文件交付；仅有静态图片、九格分镜或拼接预览**不能算完成的GIF**。如果使用图片生成工具，明确请求 GIF 格式；如果工具仅能给出逐帧图，则在获准的工具链内合成为 GIF，并检查实际文件帧数。不要凭空宣称某一模型已提供原生GIF接口：具体使用模型版本尚未核实。

## 输入

- 【源图】：原创角色参考（用户持有权属）；若未提供则使用用户明确授权的原创角色形象，不得凭空模拟私人肖像。
- 【台词】：例如“收到！”、“好玩！”、“我就看看”。优先2—6个汉字、清楚可读。
- 【情绪】：确定主导情绪及程度（惊喜、积极回应、好奇、困惑、开心）。
- 【动作】：明确起始表情、峰值动作和恢复动作，如“停顿→抬手敬礼眨眼→收手恢复”。
- 【输出模式】：默认1:1 GIF；可另附静态封面，但不能取代动画。
- 【帧数与节奏】：参考本日验证过的16帧样例；以循环稳定为先，不保证每种工具都可直接锁定具体帧率。
- 【文字】：台词固定、画面顶部安全区域，所有帧保持一致，不要随机变字。
- 【背景】：统一纯色或透明优先；透明格式需检查实际GIF透明索引，不以黑底截图冒充透明。

## 实际创作工作流

1. **锁定角色身份**：列明头发、面部、眼睛、服装、配饰、体形和材质特征，角色在所有帧中稳定；用户要求修正人物时必须以最新参考重做。
2. **单句单动作**：一张GIF只表达一个聊天语义，选主动作并安排情绪节奏。每个动作都应能在缩成聊天缩略图时读懂。
3. **循环节奏**：先建立静止0/最后帧，再做抬手、眨眼、欢呼、探头等中间动作；结束回到起始构图，降低首尾跳变。
4. **输出独立方形动图**：宽与高严格相等（用户指定1:1）。不把3×3或2×3动作分镜拼成最终动图展示。
5. **检查动态文件**：实际读取GIF宽高、帧数、每帧时长、循环信息，观察颜色变化、边缘锯齿、文字稳定、肢体插帧、首尾接续。
6. **交付与版本留存**：保留用户认可的最终动画和原始提示词调整记录；排除被否定的形象、改错前版本和外部IP未核权的联动图。

## English reusable prompt

Create one **actual looping animated GIF**, aspect ratio **1:1**, featuring the authorized original character from 【REFERENCE_IMAGE】. Lock facial features, hair, costume, body proportions and color palette throughout every frame. The short readable caption is **【TEXT】**. Emotion: 【EMOTION】. The motion follows **【STARTING_POSE】 → 【EXPRESSIVE_GESTURE】 → 【RETURN_TO_START】**, with natural easing and consistent timing. Keep the character centered, maintain generous sticker-safe margins and a stable 【BACKGROUND】. Make expressions and body language lively but coherent. The first and last frame must connect seamlessly; avoid flicker, strobe, costume drift, limb deformation or shifting lettering. Deliver a playable square **GIF file**, not a static image, slideshow or sprite sheet. Use only cleared original-character references.

## 关键控制点

**必须锁定：**源角色身份、1:1像素比例、同一台词、固定字幕、动作连贯、首尾循环。默认让动作从静止开始，中间峰值、最后回到静止；喜剧效果来自微表情和反差，不依赖快速闪屏。

**色彩与质感：**与角色原设计一致；不擅自添加未经参考的脸型、长发或全新衣服；背景简洁，适合微信小尺寸显示。不要把第三方吉祥物、IP肖像误当作用户独有素材。

## 失败纠偏

- 输出静态PNG/九宫格：重申“交付可播放的GIF文件”，检查实际帧数大于1。
- 画幅非1:1：固定宽高相等，确认导出后仍正方形；不要仅在海报上标注1:1。
- 角色不像参考：禁用自由重设计，严格复核发型、眼睛、服装和配饰；用户最新纠错优先。
- 帧间闪屏/抖动：固定镜头、背景、字幕；降低动作幅度、增加过渡帧、调整帧时长。
- 表情不够有趣：突出眉眼与身体共同表达情绪，单一动作要有起承收。
- 字符跳变或乱码：锁定同一句文字或后期用确定性排字，保持整个循环一致。
- 第三方角色权属不明：停用对外案例，仅保留内部探索，不推送公开仓库。

## 验收

读取真实文件头，宽高一致且帧数>1；能自动循环；台词语义与动作一致；无明显闪屏；动画首尾接合；原创人物身份可辨；每个角色/图像来源可公开。用户实际生成了多版，但本次仅认可已核实的方形独立GIF，**并不声称使用的具体模型、API、所有动作词均已逐个完成实测**。

## 快速用法

上传有权使用的主体照片，调用本Skill并填写【源图】【主体】【锁定特征】【输出模式】。默认3:4、柔和棚拍侧光、中性灰哑光实物雕塑；生成上下双生时固定主体身份、构图与姿势，仅改变材料呈现。标题按需添加。

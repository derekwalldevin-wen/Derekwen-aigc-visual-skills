# 刮刀堆色｜Palette Knife Impasto

## 目标与适用范围

把照片的形体转译成**由颜料本身塑形**的刮刀厚涂画，保留原主体的辨识度。成品应能看清宽刀面、颜料堆叠、沟槽、脊线、断口、翘边和一致光向的微投影；不能只是给原照叠油画滤镜。

默认输出：一张3:4竖版、单主体、暖象牙白纸底的厚涂作品。用户明确选择时，可以输出单张3:4「上方原貌／下方刮刀厚涂」对比海报。两种输出互斥，不能把双生版规则误用到单主体模式。

## 输入参数

- 【上传照片】：优先使用用户提供且有权处理的源图；没有图片时以【主体描述】生成原创示意，不声称保留某张不存在的原图。
- 【主体】：蛋糕／花朵／宠物／人物／其他；明确识别锚点与外形。
- 【原图主色／自选配色】：默认锁定原图主色及其区域关系。
- 【输出模式】：单主体厚涂（默认）／上下双生海报。
- 【画面比例】：默认3:4；若用户明确指定其他比例则相应调整构图。
- 【保留背景程度】：默认移除无关背景，仅保留淡暖白纸底。
- 【标题与文字】：默认无字；仅在明确指定教学海报时增加简洁可读标题。

缺少可识别的源图或用户未指定的参数，可使用上述默认值。涉及真人图像时不要自行推断来源许可。

## 执行流程

1. **锁定身份锚点**：提取轮廓、姿态、比例、特征色、重要局部（例如草莓位置、花瓣层数、宠物耳形）；人像优先保持五官关系、发型、服装。
2. **以刀面重构体块**：先建立少量宽厚主色块，按曲面、平面和边缘分别设置刮抹方向，再用短刀痕补充识别细节。禁止全画面覆盖同一方向的机械纹理。
3. **建立真实厚度**：颜料叠压处产生高度差，留下平刀面、拖痕、沟槽、隆起脊线、翘边、少量露底。主体全部转化为油彩质地。
4. **用光影证明厚度**：默认左上侧光，凸起处窄高光，沟槽及压边处短阴影；同一画面光向一致。
5. **处理纸底**：背景仅有轻微暖白纤维纹理，不应在整片背景堆满颜料。保持单主体完整呈现与充足留白。
6. **自检并修正**：重点核对身份、色彩分区、刀痕方向、颜料高度差与光向；若结果像平面笔刷或塑料浮雕，优先加强叠压与沟槽并去除摄影细节，而非整体锐化。

## 5分钟快速提示词

将照片中的主要主体转成刮刀厚涂油画。保留主体轮廓、主要颜色和辨识特征，用少量宽厚的颜料块概括细节。呈现刮刀压痕、沟槽、翘起边缘与颜料覆盖关系。左上方侧光照亮凸起，在沟槽和叠色边缘形成阴影。暖白纸底保持平整，突出主体颜料的厚度。3:4竖版，单主体、大留白，无文字、无画框、无拼贴。

## 完整可复用提示词

根据【上传照片】，将其中的【主体】转换成一幅具有厚颜料堆积感的刮刀油画。

主体与构图：保留原主体的主要轮廓、姿态、比例关系、特征色和辨识细节。去掉无关背景，将主体放在暖象牙白的粗纹纸面中央偏下位置，完整呈现，四周留白。画面为【画面比例，默认3:4】竖版，只有一个主要主体。

用颜料塑形：将照片细节概括为少量宽厚、具有方向性的油彩块。大色块建立形体，小刀痕补充辨识特征。让笔触顺着主体结构变化：弧面用转折的刮抹，平面用宽刀铺色，边缘用短刀收形。不同部位的刀痕方向有区别，避免全画面均匀铺满相同纹理。

厚度与层次：呈现刮刀拖过颜料留下的平坦刀面、沟槽、脊线、断口和不规则翘边。后一层颜料覆盖前一层，交叠处有可见高度差；部分边缘露出底色。主体由颜料塑形，所有区域保持一致的绘画材质，不残留照片皮肤、毛发或食物纹理。

光线：用左上方的侧向光照亮画面。凸起刀脊朝光处出现窄高光，背光处、沟槽与覆盖边缘形成短阴影。整幅画的高光与投影方向一致，厚度通过光影体现。

底面与成品：背景纸面平整，仅保留轻微纤维纹理，与主体的厚颜料形成对比。画面清楚呈现手工刮抹痕迹，不将主体做成独立的三维模型，不添加刮刀、画笔或调色盘。

配色采用【原图主色／自选配色】，保留颜色之间的区分，避免反复混色形成灰泥感。无文字、无签名、无水印、无画框、无多面板。

## 上下双生海报模式（仅按需）

整张3:4竖图分成上下两部分：上半为源照片或原创摄影风格示意；下半为**同一主体、同一机位、同一姿态和主要色彩布局**的刮刀厚涂画。两半一眼可对照，分界干净。下方必须有厚颜料实物感，不得只做抽象油画色块。

用户上传真实照片时，上半可复用其授权照片；没有源照片时，上半明确属于AI生成的虚构摄影示意，不把它称为真实原照。只有用户要求时才添加中英标题、短说明；不把独立图片排成6宫格。

## 失败判定与纠偏

| 症状 | 优先修正 |
|---|---|
| 主体变脸、变形、丢失细节 | 加强轮廓／五官／姿态／色块锚点，减少不必要的风格改写 |
| 只有油画滤镜，没有厚度 | 补充刀面、沟槽、翘边、覆盖高差和侧向短阴影 |
| 结果像塑料／陶瓷／3D模型 | 强调手工刮抹、露底、刀痕与纸面接触；去除光滑材质 |
| 所有区域刀痕一致 | 让笔触方向沿局部几何变化，大刀塑形、小刀识别 |
| 主体一半是照片、一半是油画 | 要求单主体模式全主体统一油彩材质 |
| 画面灰脏混色 | 锁定主要色块分区，减少过度融合 |
| 整张纸都浮起 | 约束厚度只发生在主体油彩，纸底保持平整 |
| 双生上下主体不一致 | 固定构图与身份锚点，再仅转换下半的媒材 |

## 复刻验收

在100%视图检查：①主体仍然可辨；②有不同方向的宽刀面；③至少清晰看到沟槽、脊线、翘边及叠压关系；④窄高光与短影方向一致；⑤主体油彩统一、纸底平整；⑥无意外文字、额外主体或不必要拼贴。若做双生海报，额外核对上下主体的一致性。

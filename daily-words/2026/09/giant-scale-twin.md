# 【AI绘画每日一词】巨物尺度双生 📱🧍

如果手机突然有一栋楼那么大，会是什么感觉？

上传一张普通照片。上半保留真实原图，下半的人还是这个人，动作、衣服和场景关系都不变，只把身边一个普通物件直接放大成“建筑级巨物”。

比如手机变成一栋楼、咖啡杯变成巨大装置、相机变成可进入的空间、鞋子变成建筑、书本变成平台、香水瓶变成玻璃高塔。

人没变。只是现实世界的尺度规则突然变了。


## 🎯核心提示词

请基于我上传的照片，制作一张独立的 **3:4竖版「巨物尺度双生」海报**，画面上下严格 **1:1分割**。

**上半：**完整保留原始照片，仅轻微统一调色。

**下半：**严格保持 **同一人物、同一张脸、同一服装、同一动作、同一主体身份和核心构图**，选择原图中的一个普通物件，将其放大为 **建筑级巨物**。

巨物可以是：**手机 / 相机 / 书 / 咖啡杯 / 鞋 / 香水瓶 / 包装盒 / 产品**。

要求：

- 巨物比人物大数十倍
- 保留原物件真实材质和结构
- 人物与巨物产生真实尺度关系
- 保持正确透视
- 保持真实接触阴影
- 保持真实空间遮挡
- 画面像真实摄影，不像玩具模型

最终效果像：**同一个人突然进入了一个普通物件被放大100倍的现实世界。**

禁止：换脸、Q版人物、把人物缩成玩具、人物从物体里钻出来、破屏效果、普通拼贴、模型感过强、明显AI畸变。

## 🔁延伸玩法

**人物照：**手机、相机、耳机、咖啡杯都可以直接放大。

**旅行照：**把行李箱、地图、相机变成巨型场景，人物像进入旅行道具世界。

**产品照：**直接让产品变成城市里的巨大装置，很适合广告视觉。

**汽车照片：**可以把车钥匙、方向盘、轮胎做成巨型空间。

**美食照片：**咖啡、蛋糕、冰淇淋、水果都能变成巨型场景。

## ⚙️关键控制点

1. 一次只放大一个东西，一个主物件最干净。
2. 人物身份要锁住：`same identity` / `same face` / `same outfit` / `same pose`。
3. 强调建筑级尺寸：`gigantic scale` / `monumental object` / `architectural scale` / `human scale contrast`。
4. 巨物材质不能变化，只改变尺度，不重新设计。
5. 用 `realistic perspective` / `contact shadow` / `natural occlusion` / `believable scale` 校正人物与巨物的空间关系。
